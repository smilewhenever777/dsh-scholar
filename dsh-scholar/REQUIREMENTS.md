# 需求规格：DSH 学者工作台插件（dsh-scholar）

> 版本 v1.0 · 2026-08-16 · 状态：需求已确认（论文目录用户自定义、图谱由对话 AI 抽取、命名"学者工作台"）

## 1. 目标

一个 DSH Web 插件，辅助科研读论文：

- **论文库**：把在 DSH 对话中 AI 看过/检索过的重点论文保存到本地论文目录，
  形成个人论文库；基于论文库构建**知识图谱**，可视化论文与概念（方法/任务/数据集）之间的关联。
- **Idea 书柜**：从重点论文中提炼"创新点"，保存为 **Idea 卡片**；卡片按多种
  维度筛选/分类/检索，随时查阅复用，成为个人的"灵感抽屉"。

数据全部保存在本地（论文目录可由用户在设置页自定义），不依赖任何外部服务。

## 2. 典型场景

1. 用户在对话里让 AI"查一下最近扩散模型的视频生成工作"，AI 检索了若干论文。
   用户说"把 LoRA 视频生成那两篇保存到论文库"，AI 调用工具保存，并自动带上
   摘要、标签与一句话总结。
2. 用户打开侧边栏"学者工作台"面板 → 论文库 Tab：搜索"video diffusion"，按年份/标签
   筛选，点开论文详情查看总结与关联卡片。
3. 用户对某篇论文的"无需训练的分割方法"印象深刻，说"把这篇的创新点记成 idea
   卡片，分类是方法"。卡片进入书柜，之后可随时按"方法"分类、⭐4 以上筛选出来。
4. 用户在"知识图谱"Tab 看到所有论文与概念的关系网络：点"LoRA"节点，
   高亮所有用到 LoRA 的论文；点某篇论文节点，看到它"改进/扩展/基于"了谁。

## 3. 功能需求

### F1 论文库（Paper Library）

- **F1.1 保存论文**（两条途径，行为一致）
  - **AI 保存**：对话中用户让 AI 保存论文 → AI 调用插件注册的工具 `paper_save`，
    提交结构化字段（标题/作者/年份/venue/arXiv id/DOI/URL/摘要/标签/一句话总结/重要度）
  - **手动添加**：客户端表单手工填写（字段同上，必填仅标题）
  - 去重：同 arXiv id / DOI / 规范化标题 已存在时，返回已存在记录并提示（不重复建；
    `update=true` 可合并更新）
- **F1.2 论文列表**：搜索（标题/作者/标签/摘要关键词）、排序
  （保存时间/发表年份/标题）、筛选（标签、年份范围、重要度）
- **F1.3 论文详情**：全部元数据 + AI 总结 + 标签 + 关联 Idea 卡片列表；
  可编辑字段、改标签、调重要度、删除
- **F1.4 本地存储**：所有论文元数据以 JSON 文件存于"论文目录"，
  一篇一文件；目录路径可在设置页配置（默认 `~/Documents/ResearchPapers`）

### F2 知识图谱（Knowledge Graph）

- **F2.1 图模型**：节点 = 论文 | 概念（方法/任务/数据集/评测指标/框架），
  边 = 有向关系（提出 proposes / 改进 improves / 扩展 extends / 基于 builds_on /
  对比 compares / 使用 uses）
- **F2.2 抽取**：由对话中的 AI 通过工具 `kg_extract` 执行（两阶段：不带 nodes/edges
  调用返回待抽取论文元数据与现有概念 → 模型组织节点/边后再次调用提交）。
  插件校验（论文节点必须真实存在、概念 id 规范化、边端点合法、去重）后写入 `graph.json`。
  支持单篇补抽与全库重建（append / rebuild）
- **F2.3 可视化**：客户端 SVG 力导向图（拖拽/缩放/平移、点选高亮）；
  论文节点 ⇄ 概念节点分列布局，边按关系类型着色；点概念节点高亮全部关联论文，
  点论文节点显示其全部关系与详情入口；支持概念过滤（1 跳子图）
- **F2.4 查询**：AI 工具 `kg_query`（某概念关联哪些论文、某论文的关系）

### F3 Idea 书柜（Idea Bookshelf）

- **F3.1 创建卡片**（两条途径）
  - **AI 创建**：用户说"把这篇的创新点记成 idea 卡片" → AI 调用 `idea_card_create`，
    提交：标题、创新点描述、来源论文 id、分类、标签、重要度、状态
  - **手动创建**：客户端表单（来源论文可从论文库选择）
- **F3.2 卡片字段**
  - 标题（必填）、创新点描述（必填）、来源论文（可空，关联论文库）
  - 分类：`method 方法` / `theory 理论` / `dataset 数据集` / `evaluation 评测` /
    `engineering 工程` / `other 其他`
  - 标签（自由多标签）、重要度 ⭐1–5、状态：`pending 待验证` / `validated 已验证` /
    `adopted 已采用` / `dropped 已搁置`
  - 创建/更新时间、备注（可空）
- **F3.3 书柜浏览**：卡片墙（网格）+ 列表切换；组合筛选：
  分类、标签、重要度、状态、来源论文、关键词；多种排序
- **F3.4 卡片详情**：完整内容 + 跳转来源论文详情 + 编辑/删除/状态流转

### F4 AI 工具集（对话中可用，共 11 个）

| 工具 | 说明 | 权限 |
|---|---|---|
| `paper_save` | 保存/更新论文（含元数据、标签、总结、重要度；arXiv id 自动归一去重；带 arxivId 自动下载 PDF） | 写 |
| `paper_fetch_pdf` | 为已入库论文下载并归档 PDF（arXiv；关键词多命中返回候选列表） | 写 |
| `paper_save_report` | 归档 deepread 精读报告 HTML 并关联论文（多命中返回候选列表） | 写 |
| `paper_search` | 在本地论文库检索（关键词/标签/年份/重要度，关键词可命中 DOI） | 读 |
| `paper_get` | 读取单篇论文完整记录 | 读 |
| `paper_update` | 更新论文元数据/标签/重要度/收集分区等（只更新提供的字段） | 写 |
| `idea_card_create` | 从论文（或独立）创建 Idea 卡片（可关联已有卡片；未知关联 id 以 droppedRelatedIds 回传） | 写 |
| `idea_card_search` | 按分类/标签/重要度/状态/关键词检索卡片 | 读 |
| `idea_card_update` | 更新卡片状态/重要度/标签等（只更新提供的字段） | 写 |
| `kg_extract` | 两阶段：准备（单篇返回完整元数据；全库只返回 unsynced ≤100 + 全库计数 + 现有概念 top 200）→ 提交节点/边（append 保留旧边；rebuild 有缩减保护 + force 确认 + graph.json.bak 备份） | 写 |
| `kg_query` | 查询图谱（某概念关联的论文、论文间关系、概念热度） | 读 |

所有写工具返回明确结果（新 id / 已存在提示），结果在对话内可见可审查。

### F5 设置（设置页 section）

- 论文目录路径（默认 `~/Documents/ResearchPapers`，可改；修改后提示手动搬迁原目录文件）
- 新建论文时默认标签（可选，自动附加到 AI/手动新建的论文）
- 设置页展示当前库统计（论文/卡片/图谱规模）

### F6 数据安全

- 全部数据本地文件存储；不收集任何遥测
- 带 body 的路由强制 `application/json`（防跨源表单投递）；请求体上限 1MB，超限即断流
- 论文/卡片 id 文件名白名单化 + Windows 保留名黑名单，防目录穿越/非法文件名
- 写文件原子化（随机后缀 tmp + rename）+ 实例级写互斥，启动加载容忍损坏文件
  （跳过并告警，清单随 /scholar/stats 的 corruptFiles 暴露）
- 精读报告读取路由带 `Content-Security-Policy: sandbox` + `nosniff`（存储型 XSS 防护）
- PDF 上传校验 `%PDF` 魔数；下载响应体上限（文本 5MB / PDF 50MB）
- REST PUT 与 dup+update 均为部分更新语义（未提交字段保持不变，防静默清空）
- kg rebuild 缩减保护（规模 > 20 且 incoming < 50% 需 force 确认；rebuild 前备份 graph.json.bak）

## 4. 非目标（v1 不做）

- 不做文献管理软件的完整功能（不解析 BibTeX 库、不做 PDF 全文检索/高亮）
- 不做在线文献数据库账号同步（zotero 等）
- 不做多用户/云同步；图谱定位是"个人研究导航图"，不追求学术级精确

## 5. 默认论文目录

- 默认：`%USERPROFILE%\Documents\ResearchPapers`（用户文档，可读性好；设置页可改）
- 目录不存在时插件自动创建：
  ```
  <论文目录>/
    papers/<id>.json       # 论文元数据，一篇一文件
    cards/<id>.json        # Idea 卡片，一卡一文件
    graph.json             # 知识图谱（节点+边）
    graph.json.bak         # rebuild 前的上一代图谱备份（保留一代）
    attachments/<id>.pdf   # PDF 附件
    reports/<id>-*.html    # deepread 精读报告归档
    collections.json       # 收集分区
  ```

## 6. 验收标准

1. 对话中让 AI 保存 3 篇论文 → 论文库出现 3 条记录，JSON 文件落盘；重复保存提示已存在
2. 论文库搜索/筛选/详情/编辑/删除可用
3. 对论文执行 `kg_extract`（两阶段）→ 图谱出现论文节点+概念节点与关系，
   可视化可拖拽高亮，概念过滤正确
4. 从一篇论文创建 2 张 idea 卡片 → 书柜按分类/重要度/状态筛选正确，详情可跳回论文
5. 设置页可改论文目录与默认标签；改目录后数据在新目录重新初始化
6. 重启 DSH 后数据仍在（文件存储）
