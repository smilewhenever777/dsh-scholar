# Changelog

## 未发布（2026-10-21）

- 统一桌面工作台的标题、卡片、表单、明暗主题和键盘焦点；侧栏宽度按实际可用空间计算，避免固定 1100px 预留导致面板过窄；保留左侧分区与独立列表滚动。

- 移除停靠面板顶部多余留白，保留原生标题栏安全区；精简头部，将次要窗口操作统一收入支持键盘的文字菜单。

- 适配官方 DSH Desktop：应用内 PDF/报告预览、宿主目录选择和原生标题栏避让；报告保留 CSP 沙箱。
- 使用宿主原生 Schemastery volatile 配置引用，修复设置落盘成功但运行中仍读取旧值。
- 共享抽屉布局与空间协调，避免多面板遮住导航；共享源码纳入公开仓库构建。
- 加载失败时禁止保存默认配置；请求保留调用方取消信号，浮窗校验完整几何并避开标题栏。
- 对话指令交付使用宿主会话输入接口，保护已有草稿及附件；补充无 Origin GET 请求的 Fetch Metadata 防护。
- 开发锁文件更新到已修复拒绝服务问题的 compression 1.8.2。

## 0.3.0 (2026-09-22)

- 修复快速评分与阅读状态更新的持久化顺序、迟到响应串页及后台刷新丢失草稿。
- 卡片保存失败明确提示，失败时保留编辑内容；对话输入保留已有文本和附件。
- 弹窗支持键盘焦点和 Escape；分区栏保持左侧默认展开，修复多篇论文无法向下滚动。
- 更新 13 个工具及数据流说明，增加可复现回归入口和打包前构建。
