# dsh-server-dashboard

DSH Web 插件：SSH 连接多台 GPU 服务器，在侧边栏展示服务器工作状态
（GPU 利用率/显存/温度/功耗、CPU/内存/磁盘、占用进程）与实验进展
（训练日志 tail + loss/epoch 曲线 + 实验结束提醒）。纯只读。
  内置 **/dash/events 即时提醒通道**（长轮询挂起推送，秒级）：实验日志停滞、
  主机离线/恢复、高温出现/解除，状态翻转即刻 toast（无需等下一轮轮询）。

- 需求规格：[REQUIREMENTS.md](./REQUIREMENTS.md)
- 架构调研：[ARCHITECTURE_NOTES.md](./ARCHITECTURE_NOTES.md)

## 功能

- **看板**：侧边栏底部显示器按钮打开；**停靠在左侧**（自动量取工作区侧栏宽度避让，
  侧栏拖宽/折叠实时跟随），与右侧的学者工作台互不冲突、可同时打开；每台主机一张卡片
  - 顶部 **GPU 热力总览条 + 舰队计数徽章**（●N 训练中 / ●N 异常 / ●N 空闲）：
    每主机一行、每卡一个色块（利用率着色，高温红框、停滞角标、离线整行红），
    点击色块直达该主机卡并弹开对应 GPU 行
  - 主区 = **固定主机全部常驻（不限数量）** + 异常主机自动上浮置顶；
    未固定的健康主机折叠在「其他服务器」
  - 主机卡头部 📌 一键固定/取消（原地点击，无需进设置页）；固定后 📌 变主题蓝
  - 主机卡头部 📥 一键收起到「其他服务器」——**离线/异常主机也不再浮回主区**；
    收起后在其他服务器里点 📤 拉回；热力图行以 📥 标记+淡化显示；设置页显示「已收起」标签
  - 抽屉拉宽时 GPU 行自动排双列（单屏可见卡数翻倍）；抽屉宽度上限为
    **窗口的 60%**（绝对上限 520px），窄窗口自动收窄、窗口恢复后自动还原
  - GPU 状态条（利用率/显存/温度/功耗）+ 每卡进程归属（**完整命令行**，一眼识别哪个实验；
    进程表默认显存降序、表头点击切换 PID 序）
  - GPU 行带**双层扫描条**（上层利用率、下层显存），忙卡不用读数字；空闲 GPU 行自动淡化
  - CPU（两次采样增量，真实瞬时值）/内存/磁盘/**1 分钟负载**、进程表、日志 tail、指标曲线
  - 卡片顶部的"训练摘要条"：epoch/loss 最新值一眼可见；**数值变化时琥珀色闪烁渐隐**
  - 折叠态异常状态显示为**琥珀色 chip**（高温/停滞/磁盘），扫一眼定位问题卡
  - 相对时间（"5 秒前"）+ 下次刷新倒计时；刷新按钮旋转反馈；图表宽度自适应抽屉，
    曲线末端钉有当前值标签、角落有量程提示
  - 图表带 **EMA 平滑**（默认开，图例行「S」开关），锯齿降噪看趋势；
    **图例悬停聚焦**（悬停某指标时其余曲线压暗）
  - **分卡 ⇄ 叠图**：同主机多卡同指标叠一张共享 Y 轴图（TensorBoard 式），
    指标下拉切换、十字线并列各卡取值——一眼看出哪张卡掉队
  - **点击图表放大**：丝滑 FLIP 缩放过渡的全屏灯箱（240px 高图、Esc/点击关闭），
    悬停微拾升提示可点
  - 每张图 **⬇ CSV 下载 / ⧉ 剪贴板复制**（长格式 series,timestamp,value）
  - 日志区**按语义着色**：ERROR/异常行红、WARNING 橙、指标数值主题蓝
  - 磁盘只平铺根分区与 >70% 挂载点，其余折叠为「+N 个挂载点」
  - GPU 展开区带背景色块 + 主题色左边线，与卡片层级清晰分离
- **SSH 连接池**：每主机一条常驻连接跨轮询复用（15s 保活、10 分钟闲置回收、
  断连自动重连并重试一次；从配置移除的主机其连接在下一轮采集时立即回收，
  无需等闲置超时）——暖轮询从 ~470ms 降到 ~125ms
- **自动发现训练日志**（两层）：
  - 设置页每台主机「🔍 发现日志」：读进程 stdout 重定向 + tee 命令行 +
    工作目录扫描（3 层深），一键选用
  - **每卡自动挂日志**：宿主自动从每张 GPU 的进程找到其日志并独立出曲线，
    无需任何配置（发现结果按 PID 缓存 5 分钟，进程不变时跳过重复探测）
- **日志解析**：`name=value` / `name: value` / `Epoch 12/100` / tqdm 进度条 /
  YOLO 定宽表格（含 `\r` 刷新与 ANSI 转义）/ JSON 行格式；
  半写行（tqdm 同行续写）与日志轮转（文件变小）时游标自动校正，不重复计点
- **曲线跨重启**：冷启动/重启后首轮从日志尾部大窗口（2MB/2000 行）种子化恢复
  最近 200 点——日志文件本身就是持久化
- **告警系统**（长轮询秒达）：
  - **崩溃告警**：GPU 从有训练进程变为无进程并持续 N 分钟（默认 5，设置可调）→ toast + **系统通知**（窗口最小化也能收到）
  - 主机失联 / 高温 / 日志停滞同链路推送；🔔 告警中心收纳本会话历史（点击条目直达对应主机/GPU）
  - toast 可点击直达对应主机卡并高亮
- **设置**：主机增删改（含从 ~/.ssh/config 导入、**主机搜索框**）、认证（密钥/密码，
  存 DSH 凭据库）、固定显示（常驻看板，不限数量）、刷新间隔（10-300s，改完即生效
  无需刷新页面）、结束判定阈值；删除主机需确认；导入后显示导入/跳过统计；界面全量中英双语
- **安全**：仅只读远程命令；**全部 /dash/* 路由仅接受 loopback 来源**
  （127.0.0.1 / ::1 / IPv4 映射 loopback；web 服务以 `--host 0.0.0.0` 对局域网
  开放时，远程主机也无法直接访问看板读/写路由，非 loopback 请求一律 403）；
  带 body 的路由强制 application/json（防跨源表单投递）；凭据经 DSH credentials
  库存储（本地 provider 为 0600 明文 + 引用分离），且**凭据名一律由服务端按
  主机 id 派生（`SD_<hostId>`）**——客户端提交的凭据名不参与凭据库寻址，
  无法借 PUT 配置覆写任意既有凭据；任何日志都不输出密钥内容

## 已知限制

- 其他用户进程的日志（如同机其他账户的训练）无法自动读取——需对方授权目录或提供凭据
- **实验结束判定为增量语义**：每轮采集比较日志 mtime/size 相对上轮是否变化（按本地
  时钟记账"最后变化时刻"），不做"本地挂钟 − 远端 mtime"直接相减——远端主机时钟
  偏移不再造成误报；首次观察到某个日志时给一个阈值时长的宽限期，看板关闭期间的
  采集空档也不会累积成"停滞"
- 离线主机进入指数退避（1→2→5→10→30 分钟），期间展示缓存的错误快照；
  看板顶部手动「刷新」清除全部退避，离线卡片上的「立即重试」只清那一台
  （需带 force=1 才生效）；**设置页保存配置同样清空全部退避**并立即按新配置重试
- /dash/events 的事件采样间隔与刷新间隔联动（下限 10 秒）：刷新间隔调大后，
  离线/高温翻转等事件的提醒时延也随之变大
- 无 GPU（或驱动异常）的机器显示 CPU/内存/磁盘，不整卡失败
- 宿主侧代码更新需完全重启桌面端/`dsh web`；客户端 UI 刷新页面即生效

## 目录

```
src/
  host/collector.ts    SSH 采集与解析（nvidia-smi/free/df/日志尾读/指标解析/自动发现）
  host/sshconfig.ts    ~/.ssh/config 解析
  index.ts             Cordis 宿主插件（settings + credentials + /dash/* 路由 + 轮询）
  client/index.tsx     客户端入口（sidebar.footer.action 触发器 + settings.section）
  client/DashboardPanel.tsx / SettingsSection.tsx / locales.ts / types.ts
scripts/               构建与测试（smoke / regression / table / discover / repair / validate…）
```

## 构建 / 安装

```sh
npm install          # 需要 HTTPS_PROXY 可用
npm run build        # tsc（宿主）+ tsdown（客户端）+ 包装器
# 安装进 web profile（父目录执行）：
dsh plugin --profile web add ./dsh-server-dashboard
# 或手动：profile package.json 加 link 依赖 + dsh.profile.bundles 加包名，pnpm install
```

## 路由

| 路由 | 方法 | 说明 |
|---|---|---|
| `/dash/snapshots` | GET | 全部主机快照（GPU/CPU/内存/磁盘/进程/日志/曲线） |
| `/dash/config` | GET/PUT | 主机配置读写（PUT 可携带密钥/密码密文） |
| `/dash/import-ssh` | GET | 解析 ~/.ssh/config 返回可导入主机 |
| `/dash/test` | POST | 连接测试（返回主机名 + GPU 数） |
| `/dash/discover-logs` | POST | 自动发现训练日志候选 |

## 安装(npm 发布版)

```sh
dsh plugin --profile web add dsh-server-dashboard
# 然后完全重启 dsh web
```

- 自定义路由(`/dash/*` `/scholar/*` `/traj/*` `/statusbar/*`)仅接受本机(loopback)访问;
  若以 `--host 0.0.0.0` 对局域网开放 Web UI,插件路由也不会暴露给远程。
- 从源码 link 安装(开发):路径含空格时 `dsh plugin add` 会写坏 profile,请按仓库内文档手工修 link。
